The Modern Java Subset: Checklist

engineering
languages
java
Twenty-five numbered substitutions for Java 25, each with the release that provides it, the mechanism it keeps out of your code, and a way to find it in an existing codebase.
Published

November 6, 2026

Twenty-five substitutions, numbered so a team can cite them. The last column gives the section that explains the item, the mechanism it keeps out of your code, and the release that provides it. The line under each construct is a detector for an existing codebase.

The mechanism links point at the criteria catalogue, where every mechanism has an anchor. They fall into three classes, and the difference matters:

  • A mechanism Java 25 still pays. The construct keeps that cost out of your code. It does not remove the mechanism from the language, because the old construct is still available to the next team. Java is still charged for it.
  • A mechanism Java stopped paying. T4, K4, and K6 are absent from Java 17 and later precisely because these constructs exist. Here the row is how to use a cost the platform already removed.
  • No mechanism. Five rows price nothing the inventory names. double for money, an instanceof cast, an unnamed tuple, a ThreadLocal, and a mutable static are correctness or attention problems. The criteria page says so itself: an agreement the inventory does not name is not priced.

What the table does not contain

Primitive types in patterns and StructuredTaskScope are previews in Java 27, so production code cannot use them yet; they are absent on purpose, not by oversight. Everything else that the page retires has a row.

The numbers are stable. A row added later takes the next number, and the anchor #item-N keeps working for every row already cited.
