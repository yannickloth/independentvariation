The Scoreboard: All 89 Languages Ranked

Every score in the 89-language comparison in one place — the ranked table, the six Core, eight Ecosystem, and six Readiness dimension sub-scores, and the complete per-language mechanism data behind each number.

1 The Scoreboard

Companion to: The Great Language Smackdown · the Criteria · the Scoring Model

This page holds every number in the comparison. Every table responds to the controls above it: type to filter, and choose a key to re-rank. The first table ranks all 89 languages by the ranking score — coupling, lifted by at most 15% for readiness — with the star band that follows from Core coupling, and shows Ecosystem coupling alongside. The next three give the per-dimension sub-scores that produce those totals. The last table gives the mechanism-presence data behind every score, so any number can be reproduced from first principles. The criteria are on the Criteria; the arithmetic, the presence rules, and the ranking rule are on the Scoring Model.

1.1 Combined Scores (All 89 Languages)

Scores from the model (saturating-sum-per-dimension), analysis date June 2026. Each version is the latest stable release at the analysis date, or another release of the same language whose page states why it is assessed — a later general-availability release, or an earlier long-lived line. Rank is the Ranking score: core × (0.85 + 0.15 × readiness / 100). A tie falls to Core Coupling, then to the newer release when both rows are releases of one language, then to the name. Coupling is primary; readiness is a modifier capped at 0.15, so a full 0-to-100 readiness swing is worth 15 coupling points at the top of the scale — the weight of one High mechanism. Readiness can therefore settle a close call, and it can never overturn a large coupling gap. Higher is better: each score is 100 minus priced cost, not a general quality measure. Each column has its own scale and its own band; do not compare across columns. The star rating reflects the Core Coupling score: 85+ = ★★★★★, 70–84 = ★★★★, 55–69 = ★★★, 40–54 = ★★, below 40 = ★. Ecosystem coupling is a lens and does not enter the ranking, because it is a dependency context rather than a quality. The table sorts by any column, so a reader who wants pure coupling sorts by that column.

1.4.1 Readiness Dimension Explanations

Reproducibility

  • 0 = the artifact rebuilds byte-identically and dependencies are pinned. A cost = the build or its dependency graph is not reproducible.

Supply chain

  • 0 = published packages carry provenance and live in a namespaced registry. A cost = origin is trusted rather than verified.

Observability

  • 0 = traces, metrics, and structured logs are standard. A cost = a running program cannot be observed with standard tooling.

Feedback

  • 0 = the edit-build-test loop is short and the editor answers as you type. A cost = a change pays a long rebuild, or the editor cannot answer.

Interop

  • 0 = the language calls other languages and compiles to a portable target. A cost = it is an island.

Governance

  • 0 = an independent body or an open specification owns the language. A cost = one vendor, or a closed specification, does.
